# 第一封邮件和交流时的问题（中文）

在完成研究者档案之后使用。先照档案第 12 节里的联系办法做。如果课题组主页写了申请方式，就按那个方式申请，不要绕开它直接发邮件。

## 第一封邮件：骨架

控制在 150 词或 300 字以内。用你自己的机构邮箱或个人邮箱发送。不要写暗示自己读过没读过的材料的话。

主题：<申请攻读博士 / 博士后 / 合作>：<一句话说共同的话题>

尊敬的<姓>教授：

我是<姓名>，目前是<现职和单位>。我读了您的<论文、年份、DOI>和<第二篇>。我对其中<一个具体的点>很感兴趣，因为<和你自己工作的联系，一句话>。

我想申请<某年入学的博士名额 / 博士后职位 / 就某主题合作>。我的背景：<两行：技能和一个带链接的成果>。我在<课题组主页或招生页面，日期>看到<关于招人或申请方式的原话>，所以按这个说明写信。<如适用：附上简历和一页纸的课题设想。>

想请教一个网页上查不到的小问题：<一个简短的问题>。

谢谢您抽空阅读。
<姓名、单位、个人主页链接>

不要写：放在谁身上都成立的赞美，把自己做过的事全列出来，没有依据的说法，以及研究者工作之外的生活。

## 问研究者的问题

1. 新来的学生或博士后最可能从哪个项目开始？日常由谁指导？
2. 署名和贡献怎么定？能否举一篇最近论文的例子？
3. 组会多久一次？平常的一周大致怎样？
4. 最近三四位学生或博士后去了哪里？课题组帮了他们什么？
5. 我要担任的职位经费有多长？某个项目到期后怎么办？
6. 一个项目做了一年还不成，通常怎么处理？

## 问现有或往届成员的问题

礼貌地问，一次一两个，被婉拒就接受。不要请任何人说导师的坏话。没有本人同意，不要引用任何人的话。

1. 你最初半年是怎么过的？
2. 需要做决定时，容易找到研究者吗？
3. 什么样的人在这个组里做得好，什么样的人会觉得难？
4. 你能自由做自己的想法吗？
5. 加入之前你希望自己知道什么？

## 收到回复之后

得到本人同意后，才把你听到的内容作为带日期、带说话人的信号条目写进档案第 8 节。私下告诉你的话，不要放进任何共享的版本。
