# Failure table

| Failure | Correction |
|---|---|
| Trait personification such as 回来、走了、躲起来 | Use 出现、分离、重新表现 or 被遮盖 |
| Riddle heading or prestige title | Name the person and object in ordinary language |
| Biography without a verified face and paper evidence | Add a licensed portrait and a legally usable numbered figure, table, or plate |
| Methods-summary Chinese as a new paragraph subject | Return to the person, material, action, or measured object |
| Several competing metaphors | Keep at most one symbol or analogy that makes a testable prediction |
| Editing away a scientific colon or ratio | Keep term definitions and values such as `3:1` |
| Companion claimed but not read | Read that companion's `SKILL.md` |
| Full PDF page used as a paper figure | Use the numbered figure or original table/plate itself |
| Every caption carries an editorial disclaimer | Describe identity, context, source, and license; clarify only a realistic confusion |
| A heading divides an action from its result | Move the heading or reorder paragraphs |
| English explainer wording appears in Chinese prose | Retain only reader-question order; rewrite from verified facts |
