# Quality bar

## Reader surface

- [ ] Title names a person and concrete question in ordinary Chinese.
- [ ] One guiding problem; no CV structure or prestige padding.
- [ ] Famous and ordinary length targets are met only when evidence supports them.
- [ ] Chinese paragraphs were revised as whole units where needed.
- [ ] Every sentence has an intelligible actor and complete predicate.
- [ ] No verification performance or editor-facing notes remain.
- [ ] The ending uses a current paper or documented reception history.

## Evidence

- [ ] S1 is complete and gaps are explicit.
- [ ] Three to five claims have evidence and boundaries before drafting.
- [ ] Body citation IDs and bibliography IDs match.
- [ ] Numeric claims are recorded in the work draft's source table.
- [ ] Coauthors and later knowledge are attributed correctly.

## Figures

- [ ] Every local file has a verified identity, source, and license.
- [ ] Copyrighted material is linked rather than redistributed unless permission allows copying.
- [ ] Any generated diagram includes exact generation instructions and the required caption.
- [ ] Every Markdown image path resolves.

## Gates

- [ ] Unit tests pass.
- [ ] Work draft passes `qc_gate.py`.
- [ ] DOI and image verification log exists.
- [ ] Human spot-check record exists.
- [ ] Reader file passes `publish_lint.py`.
- [ ] No external posting occurred without an explicit request.
